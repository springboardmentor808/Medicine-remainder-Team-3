2. Part 1: Track 3 Gaps & Deep-Dive Critique

1. Static Dictionary vs 2.5 Lakh Catalog Gap

  • Khami / Gap: Hardcoded 176 active salts for disease taxonomy and 30 for WHO limits, while the catalog contains 10,000+ unique chemical combinations.
  • Impact: Rare drugs (e.g. Pirfenidone, Tenecteplase) fall into "General Healthcare" fallback.
  • Solution: Integrate BioBERT semantic embedding matcher in Track 2 to classify long-tail formulations.

2. Refill Model: Pure-Python GBDT vs Production XGBoost

  • Khami / Gap: Trained a pure-Python Decision Stump ensemble (R²=0.9851) with MAE 1.14 days (target ≤0.85 days).
  • Impact: Works for basic estimation, but lacks Quantile Regression (P10, P50, P90 confidence intervals).
  • Solution: Retrain in production container using XGBoost with quantile loss.

3. Unit Price Calculation in Liquid vs Solid

  • Khami / Gap: Computed price/quantity gives ₹20/tablet for strips and ₹1.20/ml for syrups.
  • Solution: Explicitly format UI units (e.g. ₹20/tablet vs ₹1.20/ml or ₹6/5ml dose).

4. Local Dev SQLite vs Production PostgreSQL Trigram Search

  • Khami / Gap: PostgreSQL `pg_trgm` gives sub-15ms search; SQLite dev uses `LIKE '%q%'` (80-120ms).
  • Solution: Use Redis in-memory cache and SQLite FTS5 for local dev.

3. Part 2: Platform-Level Critical Blindspots

  • ⚠️ Background Reminder Tick Daemon Missing: Schedules are stored in DB, but no background 1-minute ticker worker (APScheduler/Redis Queue) is running to dispatch live alarms.
  • ⚠️ OCR Indian Doctor Handwriting Failure Risk: Tesseract basic OCR fails on cursive handwriting (<20% accuracy); requires Donut Vision Transformer + RxHandBD dataset.
  • ⚠️ Drug-Drug Conflict Warning Absence: Simultaneous prescription of conflicting drugs (e.g. Sildenafil + Nitrates) is not blocked without DDInter 2.0.
  • ⚠️ Frontend Hardcoded Demo Data: Frontend UI components still render mock cards instead of live API queries.
